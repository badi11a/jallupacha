# Jallupacha

Internal process-administration application. The current implementation is increment 1: local Angular/NestJS setup, Oracle persistence, fictional demo identities and sessions, profiles, macroprocesses, process types, and audit.

The demo authentication is for local development only; it does not implement REQ-25 (Google Workspace authentication). Do not expose it to a network or use it with real data.

See [Windows setup](docs/instalacion-windows.md) for prerequisites, Oracle account separation, migrations, demo data, startup, and checks. Product scope and security controls remain defined in [the specification](docs/especificacion.md), [the architecture](docs/arquitectura.md), and [AGENTS.md](AGENTS.md).
