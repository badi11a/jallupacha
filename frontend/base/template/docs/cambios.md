# Registro de cambios SDD

## Línea base 0.2.1

Aplicación generada a partir de la base frontend. El manifiesto registra procedencia; no se presume que las pruebas del proyecto consumidor hayan sido ejecutadas.

Para cada cambio registrar: requisito/principio, tarea y recorrido, clasificación del hallazgo, diseño esperado, contrato, consumidores y migración, verificación ejecutada, resultado real, revisión y pendientes. Conservar estas evidencias junto al cambio de código en Git; los mensajes de trabajo no sustituyen la especificación.
